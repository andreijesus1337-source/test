# MDTLogger — правки

Патч на два файла мода **MDTLogger**:
`scripts/4_World/MDTLogger/MDTPlayerLogger.c` и `scripts/4_World/MDTLogger/MDTLocale.c`.

## 1. Чат в Discord - только ник + сообщение

В `LogChat()` сообщение, уходящее в Discord, раньше выглядело так:

```
:speech_balloon: **Сообщение в чате**
Игрок: `hazard` (`76561199571548476`)
Сообщение: `АНДРЕЙ ХУЙ`
Позиция: `4684 / 339 / 9869`
```

Теперь — только ник и сам текст:

```
:speech_balloon: **hazard**: АНДРЕЙ ХУЙ
```

Убрано: SteamID, лейбл "Сообщение:", позиция игрока, отдельная строка-заголовок.
**Файловый лог чата** (пишется в `chat.log`) не трогали - там по-прежнему
полная информация для модерации, меняется только то, что видно в Discord.

## 2. Уведомления о начале/конце шторма EVRStorm — УСТАРЕЛО, не используется

⚠️ Этот раздел патча (категория **"storm"**: `EnableStormLog`,
`MDTDiscordConfigs.StormConfig`, `storm.log`, `LogStormEvent()`) —
**больше не подключён и можно не ставить**. Изначально уведомления
о шторме звали `MDTPlayerLogger` прямо из `EVRStormOverride.c`, но
это сломало компиляцию у ИГРОКОВ ("Can't find variable
'MDTPlayerLogger'", игра крашилась при заходе) — похоже, MDTLogger
стоит в `-servermod=` (только на сервере), а `EVRStormOverride.c`
обязан компилироваться и на клиенте тоже (там же клиентская часть
тумана).

Уведомления теперь отправляются **из самого `EVRStormOverride.c`**,
напрямую через ванильные `RestApi`/`RestContext`/`RestCallback` (без
зависимости от MDTLogger вообще) — настраивается отдельным файлом
`$profile:EVRStorm/Discord.json` (`webhookUrl`/`botName`), не через
`discord_configs.json`. См. отдельный коммит с `EVRStormOverride.c`.

Код категории "storm" в этом патче оставлен в файлах на случай, если
захотите использовать её для чего-то своего (например, продублировать
шторм и в `storm.log` вместе с остальными логами MDTLogger) — просто
знайте, что сам скрипт шторма её больше не вызывает.

## Как поставить пункт 1 (чат)

Поставьте оба файла из этого патча вместо оригинальных в PBO мода
MDTLogger, пересоберите/перезалейте.
