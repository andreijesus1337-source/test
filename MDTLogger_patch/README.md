# MDTLogger — фикс формата чата в Discord

Правка одного файла из мода **MDTLogger** (`scripts/4_World/MDTLogger/MDTPlayerLogger.c`).

## Что изменилось

В `LogChat()` сообщение, уходящее в Discord, раньше выглядело так:

```
:speech_balloon: **Сообщение в чате**
Игрок: `hazard` (`76561199571548476`)
Сообщение: `АНДРЕЙ ХУЙ`
Позиция: `4684 / 339 / 9869`
```

Теперь — только ник и сам текст:

```
:speech_balloon: **hazard**: АНДРЕЙ ХУЙ
```

Убрано: SteamID, лейбл "Сообщение:", позиция игрока, отдельная строка-заголовок.

**Файловый лог чата** (`AppendToFile(GetChatLogFile(), logLine)` чуть выше по коду)
специально НЕ трогали — там по-прежнему пишется полная информация
(ник, SteamID, сообщение, позиция) для модерации на самом сервере,
меняется только то, что видно в Discord.

## Как поставить

Замените этим файлом оригинальный
`...\MDTLogger\scripts\4_World\MDTLogger\MDTPlayerLogger.c` внутри PBO
мода MDTLogger (или в исходниках, если пересобираете сами) и пересоберите/
перезалейте мод. Остальные файлы мода (Actions.c, PlayerBase.c и т.д.)
не менялись — трогать их не нужно.
