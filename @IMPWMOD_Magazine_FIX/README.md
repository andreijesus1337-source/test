# IMPWMOD_Magazine_FIX (патч-конфиг для магазинов IMPWMOD)

Дополнение к `IMPWMOD_FIX` (стволы) — то, что забыли в первом фиксе.
Отдельный аддон, который **не трогает файлы оригинального мода**.
Требует все 27 оригинальных PBO магазинов (`requiredAddons`).

## Почему без суффикса `_FIX`/`_FIX2`

Магазин — обычный лутающийся предмет, но на его classname уже ссылаются:
- `magazines[]` у стволов (в том числе в уже готовом `IMPWMOD_FIX`),
- лут-таблицы (`types.xml`).

Если бы завести новый `IMP_Mag_XXX_FIX`, пришлось бы ещё и переписывать
`magazines[]` во всех стволах и лут-таблицах, чтобы они видели новый
магазин. Поэтому здесь, как и в `IMPWMOD_Ammo_FIX`, используется
**переопределение тем же именем класса** (`class X { ... };`, без `:`
и без предварительного объявления) — правки применяются сразу к уже
существующим магазинам, ничего больше менять не нужно.

## Единственный файл

**`Source/IMPWMOD_Magazine_FIX/config.cpp`** — один .cpp-файл. Каждый
магазин (27 стволов, 37 вариантов — некоторые "спаренные" магазины,
как у SVD/VAL/VSS, дают по 2 варианта: Tape и Clip) — свой блок,
отделённый комментарием, со всеми параметрами прямо внутри.

### Какие параметры выведены

- **Вес** (`weight`).
- **Ёмкость** (`count`) — сколько патронов вмещает магазин.
- **Размер** (`itemSize[]`).
- **Отдача/раскачка при перезарядке** (`recoilModifier[]`,
  `swayModifier[]`) — где присутствуют в оригинале.
- **Прочность** (`hitpoints`).

Не тронуты: модель/текстуры/звуки перезарядки, совместимость с
конкретными стволами (`magazines[] +=` внутри `cfgWeapons` — это
"регистрация" магазина у оружия, не параметр самого магазина).

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPWMOD_Magazine_FIX` в
   `@IMPWMOD_Magazine_FIX/Addons/IMPWMOD_Magazine_FIX.pbo`.
3. На сервере подключите **после** оригинального мода (и после
   `IMPWMOD_FIX`, если он тоже стоит):
   ```
   -mod=@IMPWMOD;@IMPWMOD_FIX;@IMPWMOD_Magazine_FIX
   ```

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
