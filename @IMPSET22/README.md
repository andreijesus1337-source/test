# IMPSET22 "Аль Катала" (DayZ mod)

Комплект одежды/снаряжения "Аль Катала": рюкзак, балаклава, обувь,
перчатки, шлем, куртка, штаны, бронежилет. Каждый предмет — отдельный
конфиг (для сборки в отдельный PBO), но теперь **все настраиваемые
параметры вынесены в один файл**, чтобы не искать их по восьми разным
`config.cpp`.

## Единый файл параметров

**`Source/IMPSET22/Set22Config.hpp`** — здесь и только здесь нужно менять:

- **имя и описание** предмета (`displayName` / `descriptionShort`);
- **размеры** в инвентаре (`itemSize`, `itemsCargoSize`);
- **вес** (`weight`) и утепление (`heatIsolation`);
- **прочность** предмета (`hitpoints`, а также `durability` у обуви);
- **защиту/урон** — биологическая защита (`Protection.biological`) и
  снижение входящего урона (`GlobalArmor.damage`, одинаково применяется
  к пулям/ударам/зомби/гранатам).

Каждый `Set22/<Предмет>/config.cpp` подключает этот файл через
`#include "\IMPSET22\Set22Config.hpp"` и использует именованные константы
(`IMPSET22_HELMET_ARMOR_DAMAGE` и т.п.) вместо чисел прямо в теле класса.
Меняете число в `Set22Config.hpp` — оно применяется везде, где эта
константа используется, при следующей пересборке PBO.

> Про `GlobalArmor.damage` / `Protection.biological`: это доля урона,
> которая **проходит** через предмет: `0.0` = блокирует весь урон
> (максимальная защита), `1.0` = защиты нет. Чем меньше число — тем
> лучше защита.

## Структура

```
@IMPSET22/
├── mod.cpp
├── README.md
└── Source/
    └── IMPSET22/
        ├── config.cpp              # CfgPatches/CfgMods/анимации P3D — не содержит балансных чисел
        ├── Set22Config.hpp         # <-- единый файл параметров (редактировать здесь)
        ├── Scripts/4_World/...     # скрипты предметов + IK-анимации
        └── Set22/
            ├── Backpack/config.cpp
            ├── Balaclava/config.cpp
            ├── Boots/config.cpp
            ├── Gloves/config.cpp
            ├── Helmet/config.cpp
            ├── Jacket/config.cpp
            ├── Pants/config.cpp
            └── Vest/config.cpp
```

Цветовые варианты предметов (`_2`, `_1` и т.д.) переопределяют только
модель/текстуры — они наследуют все параметры от `..._ColorBase` и
подтягивают те же макросы, где параметры продублированы явно (например,
`hitpoints` во втором варианте шлема).

## Сборка PBO

1. Установите **DayZ Tools** через Steam (нужен `AddonBuilder`).
2. Скопируйте `Source/IMPSET22` в P:\ драйв-структуру так, чтобы путь
   получился `P:\IMPSET22\...` (это важно: все `#include` и пути к
   моделям в конфигах абсолютные, от корня `IMPSET22`).
3. Соберите **отдельным PBO** каждую из следующих папок (у каждой свой
   `config.cpp` с собственным `CfgPatches`):
   - `P:\IMPSET22` → `@IMPSET22\Addons\IMPSET22.pbo` (ядро + скрипты/анимации)
   - `P:\IMPSET22\Set22\Backpack` → `IMP_Bag_SET22.pbo`
   - `P:\IMPSET22\Set22\Balaclava` → `IMP_Balaclava_SET22.pbo`
   - `P:\IMPSET22\Set22\Boots` → `IMP_Boots_SET22.pbo`
   - `P:\IMPSET22\Set22\Gloves` → `IMP_Gloves_SET22.pbo`
   - `P:\IMPSET22\Set22\Helmet` → `IMP_Helmet_SET22.pbo`
   - `P:\IMPSET22\Set22\Jacket` → `IMP_Jacket_SET22.pbo`
   - `P:\IMPSET22\Set22\Pants` → `IMP_Pants_SET22.pbo`
   - `P:\IMPSET22\Set22\Vest` → `IMP_Vest_SET22.pbo`
4. Так как `Set22Config.hpp` подключается по абсолютному пути
   `\IMPSET22\Set22Config.hpp`, он должен физически лежать по адресу
   `P:\IMPSET22\Set22Config.hpp` — тогда AddonBuilder найдёт его при
   сборке **любого** из перечисленных PBO, независимо от того, что
   собирается отдельная подпапка.

Итоговая структура мода:

```
@IMPSET22/
├── mod.cpp
└── Addons/
    ├── IMPSET22.pbo
    ├── IMP_Bag_SET22.pbo
    ├── IMP_Balaclava_SET22.pbo
    ├── IMP_Boots_SET22.pbo
    ├── IMP_Gloves_SET22.pbo
    ├── IMP_Helmet_SET22.pbo
    ├── IMP_Jacket_SET22.pbo
    ├── IMP_Pants_SET22.pbo
    └── IMP_Vest_SET22.pbo
```

## Установка на сервер

```
-mod=@IMPSET22
```

Пожалуйста, соберите и протестируйте мод у себя перед использованием на
живом сервере.
