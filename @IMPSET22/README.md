# IMPSET22 "Аль Катала" (DayZ mod)

Комплект одежды/снаряжения "Аль Катала": рюкзак, балаклава, обувь,
перчатки, шлем, куртка, штаны, бронежилет. Весь набор собирается в
**один PBO**, а **все настраиваемые параметры вынесены в один файл**,
чтобы не искать их по коду.

## Единый файл параметров

**`Source/IMPSET22/Set22Config.hpp`** — здесь и только здесь нужно менять:

- **имя и описание** предмета (`displayName` / `descriptionShort`);
- **размеры** в инвентаре (`itemSize`, `itemsCargoSize`);
- **вес** (`weight`) и утепление (`heatIsolation`);
- **прочность** предмета (`hitpoints`, а также `durability` у обуви);
- **защиту/урон** — биологическая защита (`Protection.biological`) и
  снижение входящего урона (`GlobalArmor.damage`, одинаково применяется
  к пулям/ударам/зомби/гранатам).

`Source/IMPSET22/config.cpp` подключает этот файл через
`#include "Set22Config.hpp"` и использует именованные константы
(`IMPSET22_HELMET_ARMOR_DAMAGE` и т.п.) вместо чисел прямо в теле класса.
Меняете число в `Set22Config.hpp` — оно применяется везде, где эта
константа используется, при следующей пересборке PBO.

> Про `GlobalArmor.damage` / `Protection.biological`: это доля урона,
> которая **проходит** через предмет: `0.0` = блокирует весь урон
> (максимальная защита), `1.0` = защиты нет. Чем меньше число — тем
> лучше защита.

## Структура

```
@IMPSET22/
├── mod.cpp
├── README.md
└── Source/
    └── IMPSET22/
        ├── config.cpp              # CfgPatches/CfgMods/CfgVehicles — все 8 предметов + анимации P3D
        ├── Set22Config.hpp         # <-- единый файл параметров (редактировать здесь)
        └── Scripts/4_World/...     # скрипты предметов + IK-анимации
```

Все восемь предметов (и их цветовые варианты `_2`, `_1` и т.д.) объявлены
как соседние классы внутри одного `class CfgVehicles { ... }` в
`config.cpp` и наследуются от общего `class Clothing`, объявленного один
раз. Раньше у каждого предмета был свой `config.cpp`/PBO — теперь всё
собирается в один `IMPSET22.pbo`.

> Если понадобится снова разрешить серверу включать/выключать предметы
> набора по отдельности — этого можно добиться, разнеся классы обратно
> по папкам с собственным `CfgPatches` на каждую, но тогда потеряется
> удобство одного PBO.

## Сборка PBO

1. Установите **DayZ Tools** через Steam (нужен `AddonBuilder`).
2. Скопируйте `Source/IMPSET22` в вашу P:\ драйв-структуру (или укажите
   AddonBuilder эту папку напрямую — она уже содержит `config.cpp` и
   `Scripts/`, как требует Addon Builder).
3. Запустите AddonBuilder, укажите:
   - Source folder: `Source/IMPSET22`
   - Destination: `@IMPSET22/Addons/IMPSET22.pbo`
4. Убедитесь, что бинаризация прошла без ошибок.

Итоговая структура мода:

```
@IMPSET22/
├── mod.cpp
└── Addons/
    └── IMPSET22.pbo
```

## Установка на сервер

```
-mod=@IMPSET22
```

Пожалуйста, соберите и протестируйте мод у себя перед использованием на
живом сервере.
