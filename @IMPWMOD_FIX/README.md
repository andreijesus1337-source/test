# IMPWMOD_FIX (патч-конфиг для оружейного мода IMPWMOD)

Отдельный аддон, который **не трогает файлы оригинального оружейного
мода**. Требует все 104 оригинальных PBO этого мода (`requiredAddons`)
и добавляет 153 новых класса стволов с суффиксом `_FIX`, унаследованных
от оригинальных — модели, звуки, анимации, частицы, оптика и т.п.
берутся из оригинала автоматически, через наследование, без единого
указания пути к ассетам.

## Единственный файл

**`Source/IMPWMOD_FIX/config.cpp`** — один .cpp-файл (~3500 строк).
Каждый физический ствол — свой блок, отделённый комментарием
(`// AUTOMATIC - AK12`, `// SNIPER - AWM` и т.д.), внутри — все его
цветовые/комплектационные варианты из оригинала (не только первый),
каждый со своими параметрами прямо в теле класса — обычными числами,
без макросов.

### Какие параметры выведены (на весь пак)

- **Вес и размер** (`weight`, `itemSize[]`).
- **Разброс по режимам стрельбы** (`dispersion` — свой для каждого
  режима: одиночный/очередь/автомат/`Single` у болтовых винтовок).
- **Отдача** (`recoilModifier[]`) — где присутствует в оригинале.
- **Прочность** (`hitpoints`, `DamageSystem > GlobalHealth > Health`).
- **Совместимые магазины** (`magazines[]`) — где есть сменный магазин;
  у стволов с внутренним магазином (PTRD, K98, Anzio, CSR50, RN50,
  M590A1, M870, M32, Rev50BMG, SVLK-14S "Sumrak") это поле пустое в
  оригинале и потому не продублировано.

Не тронуты: модель/текстуры/звуки/частицы/анимации, `PPDOFProperties`,
`swayModifier`, `reloadTime`, оптика (`OpticsInfo`) — их можно добавить
по такому же принципу, если понадобится.

### Охват по категориям

| Категория | Файлов | Вариантов стволов |
|---|---|---|
| automatic | 39 | 52 |
| sniper | 45 | 76 |
| Submachine (пулемёты) | 7 | 11 |
| Shotgun | 6 | 6 |
| SMG | 4 | 5 |
| Pistol | 2 | 2 |
| GrenadeLauncher | 1 | 1 |
| **Итого** | **104** | **153** |

Не включены `weapons/ammo/*` (патроны/цинки — там своя структура,
`CfgMagazines`, а не `cfgWeapons`) и `weapons/VanillaRebalance/*` (это
патчи совместимости магазинов для ВАНИЛЬНОГО оружия игры, а не новые
стволы). Если нужно вынести и их — делается по тому же принципу
отдельным блоком.

> **Важно.** Так как `_FIX` — это НОВЫЕ классы (не оригинальные), в игре
> они появятся ДОПОЛНИТЕЛЬНО к оригинальным стволам, с исходными
> характеристиками. Чтобы игроки получали именно исправленную версию,
> впишите classname с `_FIX` в свои типы/лут-таблицы (`types.xml`,
> торговцев и т.п.) вместо оригинальных имён.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPWMOD_FIX` в `@IMPWMOD_FIX/Addons/IMPWMOD_FIX.pbo`.
3. На сервере подключите **после** оригинального оружейного мода:
   ```
   -mod=@IMPWMOD;@IMPWMOD_FIX
   ```
   (порядок важен — `_FIX` должен грузиться после оригинала, так как
   ссылается на его классы).

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере — файл сгенерирован автоматически из 104 исходных конфигов,
но перед продакшеном стоит хотя бы выборочно проверить пару стволов
в игре.
