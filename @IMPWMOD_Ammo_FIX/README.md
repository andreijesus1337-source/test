# IMPWMOD_Ammo_FIX (патч-конфиг для патронов IMPWMOD)

Отдельный аддон, который **не трогает файлы оригинального оружейного
мода**. Требует все 15 оригинальных PBO блока патронов (14 калибров +
`IMP_Bullet_Projectiles`) и переопределяет их параметры.

## Чем этот патч отличается от `IMPWMOD_FIX` (оружие)

Для стволов мы создавали НОВЫЕ классы с суффиксом `_FIX` (наследники
оригинала) — так надо, потому что ствол это лутающийся предмет, и
администратору нужно решить, заменять ли им оригинал в `types.xml`.

Патроны устроены иначе:
- **Патрон** (`CfgMagazines`) и **цинк** (`CfgVehicles`) — обычные
  лутающиеся предметы, как и ствол.
- Но **реальный урон пули** (`CfgAmmo`) — это НЕ отдельный предмет,
  на него просто ссылаются по имени (`ammo = "IMP_Bullet_XXX"` в
  патроне). Если бы для него сделать новый `_FIX`-класс, эту ссылку
  пришлось бы всё равно менять в куче других мест — а если её не
  трогать, `_FIX`-класс просто ничем не использовался бы.

Поэтому здесь везде используется **переопределение тем же именем
класса, без наследования** (`class X { ... };` — без `:` и без
предварительного объявления) — стандартный приём для патчей
совместимости в Arma/DayZ: движок сам сливает классы с одинаковым
путём/именем из разных загруженных PBO по порядку `requiredAddons`,
никакого `:` для этого не нужно. Изменения применяются сразу к уже
существующим патронам/цинкам/урону, `types.xml` трогать не нужно
вообще.

> Если писали `class X; class X : X { ... };` (с наследованием от
> самого себя) — так делать не надо: Rapify считает это дублирующимся
> объявлением класса и падает с `duplicated token or class` при сборке
> PBO. Именно поэтому здесь используется простое переобъявление имени
> без `:`.

## Единственный файл

**`Source/IMPWMOD_Ammo_FIX/config.cpp`** — один .cpp-файл, три раздела:

- `class cfgAmmo` — урон пули (`Health`/`Blood`/`Shock` в
  `DamageApplied`) для всех 14 калибров.
- `class CfgMagazines` — сам патрон/пачка: вес, количество патронов в
  пачке (`count`), размер в инвентаре, прочность.
- `class CfgVehicles` — цинк (коробка): вес, размер, прочность. У
  некоторых калибров по два размера цинка (например, 100 и 15 патронов) —
  оба учтены отдельными блоками.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPWMOD_Ammo_FIX` в
   `@IMPWMOD_Ammo_FIX/Addons/IMPWMOD_Ammo_FIX.pbo`.
3. На сервере подключите **после** оригинального оружейного мода:
   ```
   -mod=@IMPWMOD;@IMPWMOD_Ammo_FIX
   ```

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере — файл сгенерирован автоматически из 15 исходных конфигов
(14 калибров + общий файл пуль), но перед продакшеном стоит хотя бы
выборочно проверить пару калибров в игре.
