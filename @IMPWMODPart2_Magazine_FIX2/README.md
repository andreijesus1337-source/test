# IMPWMODPart2_Magazine_FIX2 (патч-конфиг для магазинов второго набора)

Аналог `IMPWMOD_Magazine_FIX`, но для магазинов **второго** оружейного
набора (`IMPWMODPart2`). Отдельный аддон, который **не трогает файлы
оригинального мода**.

## Важное открытие: паки зависят друг от друга по магазинам

Присланный файл (`Weapons/Attachments/Magazine/AK74/config.cpp`) —
это магазины именно **второго** набора (пути в нём — `IMPWMODPart2\...`).
Но их classname (`IMP_Mag_AK74_6L18_45Rnd`, `IMP_Mag_AK74_6L20_30Rnd`
и т.д.) уже прописаны в `magazines[]` у **AK12 из первого набора**
(в уже готовом `IMPWMOD_FIX`). То есть это не дублирование — оружие
первого пака ссылается на магазины, которые физически определены во
втором паке. Оба набора оружия и магазинов на сервере должны стоять
вместе, иначе у AK12 (и, вероятно, других стволов первого пака) часть
магазинов из списка совместимых будет не найдена.

## Пока покрыт только AK74

Прислан один файл — обработал его полностью (11 вариантов магазина:
6L18, 6L20, 6L23, 6L23P, 6L26, 6L31, DTSaiga 10/20, PMag/PMag FDE,
барабан на 95). Остальные магазины второго набора добавлю в этот же
файл по мере присылки — структура и подход те же, менять ничего не
придётся, только дополнить.

## Почему без суффикса `_FIX2` у классов магазинов

Так же, как в `IMPWMOD_Magazine_FIX`: магазин — лутающийся предмет, но
на его classname уже ссылаются `magazines[]` у стволов (в обоих уже
готовых фиксах — `IMPWMOD_FIX` и `IMPWMODPart2_FIX2`) и лут-таблицы.
Поэтому используется **переопределение тем же именем класса**
(`class X { ... };`, без `:` и без forward declare) — правки
применяются сразу, ничего больше менять не нужно.

## Единственный файл

**`Source/IMPWMODPart2_Magazine_FIX2/config.cpp`** — вес, ёмкость
(`count`), размер, отдача/раскачка при перезарядке, прочность для
каждого варианта магазина.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPWMODPart2_Magazine_FIX2` в
   `@IMPWMODPart2_Magazine_FIX2/Addons/IMPWMODPart2_Magazine_FIX2.pbo`.
3. На сервере подключите после оригинальных модов:
   ```
   -mod=@IMPWMOD;@IMPWMOD_FIX;@IMPWMOD_Magazine_FIX;@IMPWMODPart2;@IMPWMODPart2_FIX2;@IMPWMODPart2_Magazine_FIX2
   ```

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
