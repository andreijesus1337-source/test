# IMPWMODPart2_FIX2 (патч-конфиг для второго набора оружия)

Отдельный аддон, который **не трогает файлы оригинального оружейного
мода**. Требует все 42 оригинальных PBO этого набора (`requiredAddons`)
и добавляет 59 новых классов стволов с суффиксом `_FIX2` (по аналогии
с `IMPWMOD_FIX`, но другой суффикс — чтобы не конфликтовать с ним, если
оба патча стоят на сервере одновременно), унаследованных от оригинальных
— модели, звуки, анимации, частицы, оптика и т.п. берутся из оригинала
автоматически, через наследование, без единого указания пути к ассетам.

## Единственный файл

**`Source/IMPWMODPart2_FIX2/config.cpp`** — один .cpp-файл (~1365 строк).
Каждый физический ствол — свой блок, отделённый комментарием
(`// AUTOMATIC - GROZA`, `// SNIPER - OSV` и т.д.), внутри — все его
цветовые/комплектационные варианты из оригинала, каждый со своими
параметрами прямо в теле класса — обычными числами, без макросов.

### Какие параметры выведены

- **Вес и размер** (`weight`, `itemSize[]`).
- **Разброс по режимам стрельбы** (`dispersion`).
- **Отдача** (`recoilModifier[]`) — где присутствует в оригинале.
- **Прочность** (`hitpoints`) — где переопределена в оригинале; у
  `IMP_Pistol_Beretta_Desert_FIX2` её нет, потому что в оригинале она
  тоже не переопределена (наследуется от ванильного класса) — блок
  `DamageSystem` для него не добавлен, чтобы не изобретать значение.
- **Совместимые магазины** (`magazines[]`) — где есть сменный магазин;
  у 5 стволов с внутренним магазином/однозарядных (M1941, Winchester1873,
  ChinaLake, MagnumSuperSport, RagingBull) поле пустое в оригинале и
  потому не продублировано.

### Охват по категориям

| Категория | Файлов | Вариантов стволов |
|---|---|---|
| Automatic | 15 | 20 |
| Pistol | 14 | 20 |
| SMG | 5 | 10 |
| Sniper | 5 | 5 |
| LMG | 2 | 3 |
| GrL (гранатомёт) | 1 | 1 |
| **Итого** | **42** | **59** |

> **Важно.** Так как `_FIX2` — это НОВЫЕ классы (не оригинальные), в игре
> они появятся ДОПОЛНИТЕЛЬНО к оригинальным стволам, с исходными
> характеристиками. Чтобы игроки получали именно исправленную версию,
> впишите classname с `_FIX2` в свои типы/лут-таблицы (`types.xml`,
> торговцев и т.п.) вместо оригинальных имён.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPWMODPart2_FIX2` в
   `@IMPWMODPart2_FIX2/Addons/IMPWMODPart2_FIX2.pbo`.
3. На сервере подключите **после** оригинального оружейного мода:
   ```
   -mod=@IMPWMODPart2;@IMPWMODPart2_FIX2
   ```
   (порядок важен — `_FIX2` должен грузиться после оригинала, так как
   ссылается на его классы).

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере — файл сгенерирован автоматически из 42 исходных конфигов, но
перед продакшеном стоит хотя бы выборочно проверить пару стволов в игре.
