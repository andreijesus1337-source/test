# IMPSET22_FIX (патч-конфиг для IMPSET22 "Аль Катала")

Отдельный аддон, который **не трогает файлы оригинального мода**
IMPSET22. Требует оригинальные PBO этого мода (`requiredAddons`) и
добавляет 8 новых классов вещей с суффиксом `_FIX`, унаследованных от
оригинальных — модели, текстуры, звуки, скрипты и анимации берутся из
оригинала автоматически, через наследование, без единого указания пути.

## Единственный файл

**`Source/IMPSET22_FIX/config.cpp`** — один .cpp-файл, в начале которого
лежат все `#define` с параметрами (имя, описание, размер, вес,
утепление, влагостойкость, прочность, защита). Меняете число — меняются
характеристики соответствующего `_FIX`-предмета при следующей пересборке
PBO. Дальше в файле ничего искать не нужно.

### Что настроено сейчас

| Оригинальный класс | Новый класс | Название |
|---|---|---|
| `IMP_Bag_SET22` | `IMP_Bag_SET22_FIX` | Рюкзак Аль Катала |
| `IMP_Balaclava_SET22` | `IMP_Balaclava_SET22_FIX` | Балаклава Аль Катала |
| `IMP_Boots_SET22` | `IMP_Boots_SET22_FIX` | Обувь Аль Катала |
| `IMP_Gloves_SET22` | `IMP_Gloves_SET22_FIX` | Перчатки Аль Катала |
| `IMP_Helmet_SET22` | `IMP_Helmet_SET22_FIX` | Шлем Аль Катала |
| `IMP_Jacket_SET22` | `IMP_Jacket_SET22_FIX` | Куртка Аль Катала |
| `IMP_Pants_SET22_1` | `IMP_Pants_SET22_1_FIX` | Штаны Аль Катала |
| `IMP_Vest_SET22_1` | `IMP_Vest_SET22_1_FIX` | Бронежилет Аль Катала |

Все восемь `_FIX`-вещей: не намокают (`varWetMax = 0`), блокируют 80%
входящего урона (пули/удары/зомби/гранаты), у балаклавы и шлема
дополнительно 80% био-защиты (от заражения), плюс собственные
лорные названия/описания, размеры, вес и утепление.

> **Важно.** Так как `_FIX` — это НОВЫЕ классы (не оригинальные), в игре
> они появятся ДОПОЛНИТЕЛЬНО к оригинальным вещам, с исходными
> характеристиками. Чтобы игроки получали именно исправленную версию,
> впишите `classname` c `_FIX` в свои типы/лут-таблицы (`types.xml` и
> т.п.) вместо оригинальных имён.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPSET22_FIX` в `@IMPSET22_FIX/Addons/IMPSET22_FIX.pbo`.
3. На сервере подключите **после** оригинального мода:
   ```
   -mod=@IMPSET22;@IMPSET22_FIX
   ```
   (порядок важен — `_FIX` должен грузиться после оригинала, так как
   ссылается на его классы).

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
