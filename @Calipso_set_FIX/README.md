# Calipso_set_FIX (патч-конфиг для набора Calipso)

Отдельный аддон, который **не трогает файлы оригинального мода**
Calipso_set (`Fruck_EquipmentPackSets`). Требует оригинальные PBO этого
мода (`requiredAddons`) и добавляет 7 новых классов вещей с суффиксом
`_FIX`, унаследованных от оригинальных — модели, текстуры, звуки,
скрипты и анимации берутся из оригинала автоматически, через
наследование, без единого указания пути.

В отличие от наборов IMPSET21/IMPSET22, здесь у каждой вещи всего один
вариант (без цветов) — поэтому по одному классу `_FIX` на вещь, всего 7.

## Единственный файл

**`Source/Calipso_set_FIX/config.cpp`** — один .cpp-файл. Каждая вещь —
самостоятельный блок класса `<Оригинал>_FIX`, отделённый комментарием
(`// BOOTS`, `// HELMET` и т.д.), со всеми параметрами прямо внутри —
обычными числами, без макросов. Правите нужную вещь в её собственном
блоке, остальные не трогаете.

### Что настроено сейчас

| Оригинальный класс | Новый класс | Название |
|---|---|---|
| `Fruck_Calipso_Shoes` | `Fruck_Calipso_Shoes_FIX` | Ботинки Calipso |
| `Fruck_Calipso_gloves` | `Fruck_Calipso_gloves_FIX` | Перчатки Calipso |
| `Fruck_Calipso_Helmet` | `Fruck_Calipso_Helmet_FIX` | Шлем Calipso |
| `Fruck_Calipso_Jacket` | `Fruck_Calipso_Jacket_FIX` | Куртка Calipso |
| `Fruck_Calipso_Mask` | `Fruck_Calipso_Mask_FIX` | Маска Calipso |
| `Fruck_Calipso_Pants` | `Fruck_Calipso_Pants_FIX` | Штаны Calipso |
| `Fruck_Calipso_Vest` | `Fruck_Calipso_Vest_FIX` | Бронежилет Calipso |

Названия и описания оставлены оригинальные — в этом моде они уже были
осмысленными (не общий плейсхолдер, как в IMPSET21/22), переписывать не
стал.

Что изменено у всех семи вещей:
- **Не намокают** (`varWetMax = 0`, в оригинале было от 0.249 до 1.0).
- **80% защита от урона** (`GlobalArmor.damage = 0.2` по всем
  Projectile/Melee/Infected/FragGrenade). В оригинале защита была очень
  разной и часто неполной: у ботинок её не было вовсе, у куртки и штанов
  был только Melee/Infected (без Projectile/FragGrenade), у шлема и
  маски уже было лучше 80% (0.12 → сейчас у всех ровно 0.2 для
  единообразия), у жилета урон был разным по типам (0–0.6). Теперь везде
  ровно 80% по всем типам.
- **Био-/хим-защита 80%** — у перчаток (`biological`, `chemical`; было
  100%/100%), у шлема и маски (`biological`; было 25%).
- **Прочность (`hitpoints`) не менялась** — оставлена как в оригинале
  (у каждой вещи своя: ботинки 100, перчатки 165, шлем 200, куртка 140,
  маска 200, штаны 100, жилет 225).

> **Важно.** Так как `_FIX` — это НОВЫЕ классы (не оригинальные), в игре
> они появятся ДОПОЛНИТЕЛЬНО к оригинальным вещам, с исходными
> характеристиками. Чтобы игроки получали именно исправленную версию,
> впишите classname с `_FIX` в свои типы/лут-таблицы (`types.xml` и
> т.п.) вместо оригинальных имён.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/Calipso_set_FIX` в
   `@Calipso_set_FIX/Addons/Calipso_set_FIX.pbo`.
3. На сервере подключите **после** оригинального мода, например:
   ```
   -mod=@Calipso_set;@Calipso_set_FIX
   ```
   (порядок важен — `_FIX` должен грузиться после оригинала, так как
   ссылается на его классы).

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
