# IMPSET21_FIX (патч-конфиг для IMPSET21 "Megalith")

Отдельный аддон, который **не трогает файлы оригинального мода**
IMPSET21. Требует оригинальные PBO этого мода (`requiredAddons`) и
добавляет 22 новых класса вещей с суффиксом `_FIX`, унаследованных от
оригинальных — по одному `_FIX`-классу на КАЖДЫЙ существующий цветовой
вариант каждой вещи (не только на первый цвет). Модели, текстуры,
звуки, скрипты и анимации берутся из оригинала автоматически, через
наследование, без единого указания пути.

## Единственный файл

**`Source/IMPSET21_FIX/config.cpp`** — один .cpp-файл. Каждая вещь —
самостоятельный блок класса `<Оригинал>_FIX`, отделённый комментарием
(`// BACKPACK`, `// HELMET` и т.д.), со всеми параметрами прямо внутри —
обычными числами, без макросов. Правите нужную вещь в её собственном
блоке, остальные не трогаете.

### Что настроено сейчас

| Вещь | Оригинальные классы (цвета) | Новые классы |
|---|---|---|
| Рюкзак | `IMP_Bag_SET21`, `IMP_Bag_SET21_2` | те же + `_FIX` |
| Балаклава | `IMP_Balaclava_SET21`, `IMP_Balaclava_SET21_2` | те же + `_FIX` |
| Ремень | `IMP_Belt_SET21`, `IMP_Belt_SET21_2` | те же + `_FIX` |
| Обувь | `IMP_Boots_SET21`, `IMP_Boots_SET21_2` | те же + `_FIX` |
| Шлем | `IMP_Helmet_SET21`, `IMP_Helmet_SET21_2` | те же + `_FIX` |
| Куртка | `IMP_Jacket_SET21_1`, `_2`, `_1_2`, `_2_2` | те же + `_FIX` (4 варианта) |
| Штаны | `IMP_Pants_SET21_1`, `_2`, `_1_2`, `_2_2` | те же + `_FIX` (4 варианта) |
| Бронежилет | `IMP_Vest_SET21_1`, `IMP_Vest_SET21_2` | те же + `_FIX` |
| Подсумки | `IMP_SET21_Pouch_Blue`, `IMP_SET21_Pouch_Black` | те же + `_FIX` |

Итого 22 `_FIX`-класса — по одному на каждый цветовой вариант каждой
вещи. Внутри одной вещи все цвета получают одинаковые характеристики
(меняется только внешний вид, как и в оригинале): не намокают
(`varWetMax = 0`, кроме подсумка — у него в оригинале не было
влагостойкости), блокируют 80% входящего урона (пули/удары/зомби/
гранаты; у рюкзака, балаклавы, ремня, обуви и подсумка в оригинале
защиты не было вовсе — добавлена целиком), у балаклавы и шлема
дополнительно 80% био-защиты (от заражения), плюс собственные лорные
описания.

> **Важно.** Так как `_FIX` — это НОВЫЕ классы (не оригинальные), в игре
> они появятся ДОПОЛНИТЕЛЬНО к оригинальным вещам, с исходными
> характеристиками. Чтобы игроки получали именно исправленную версию,
> впишите classname с `_FIX` в свои типы/лут-таблицы (`types.xml` и
> т.п.) вместо оригинальных имён — для каждого нужного цвета отдельно.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPSET21_FIX` в `@IMPSET21_FIX/Addons/IMPSET21_FIX.pbo`.
3. На сервере подключите **после** оригинального мода:
   ```
   -mod=@IMPSET21;@IMPSET21_FIX
   ```
   (порядок важен — `_FIX` должен грузиться после оригинала, так как
   ссылается на его классы).

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
