# IMPSET21_FIX (патч-конфиг для IMPSET21 "Megalith")

Отдельный аддон, который **не трогает файлы оригинального мода**
IMPSET21. Требует оригинальные PBO этого мода (`requiredAddons`) и
добавляет 9 новых классов вещей с суффиксом `_FIX`, унаследованных от
оригинальных — модели, текстуры, звуки, скрипты и анимации берутся из
оригинала автоматически, через наследование, без единого указания пути.

## Единственный файл

**`Source/IMPSET21_FIX/config.cpp`** — один .cpp-файл. Каждая вещь —
самостоятельный блок класса `<Оригинал>_FIX`, отделённый комментарием
(`// BACKPACK`, `// HELMET` и т.д.), со всеми параметрами прямо внутри —
обычными числами, без макросов. Правите нужную вещь в её собственном
блоке, остальные не трогаете.

### Что настроено сейчас

| Оригинальный класс | Новый класс | Название |
|---|---|---|
| `IMP_Bag_SET21` | `IMP_Bag_SET21_FIX` | Рюкзак Megalith |
| `IMP_Balaclava_SET21` | `IMP_Balaclava_SET21_FIX` | Балаклава Megalith |
| `IMP_Belt_SET21` | `IMP_Belt_SET21_FIX` | Ремень Megalith |
| `IMP_Boots_SET21` | `IMP_Boots_SET21_FIX` | Обувь Megalith |
| `IMP_Helmet_SET21` | `IMP_Helmet_SET21_FIX` | Шлем Megalith |
| `IMP_Jacket_SET21_1` | `IMP_Jacket_SET21_1_FIX` | Куртка Megalith |
| `IMP_Pants_SET21_1` | `IMP_Pants_SET21_1_FIX` | Штаны Megalith |
| `IMP_Vest_SET21_1` | `IMP_Vest_SET21_1_FIX` | Бронежилет Megalith |
| `IMP_SET21_Pouch_Blue` | `IMP_SET21_Pouch_Blue_FIX` | Подсумки Megalith |

Все девять `_FIX`-вещей: не намокают (`varWetMax = 0`, кроме подсумка —
у него в оригинале не было влагостойкости), блокируют 80% входящего
урона (пули/удары/зомби/гранаты; у рюкзака, балаклавы, ремня, обуви и
подсумка в оригинале защиты не было вовсе — добавлена целиком), у
балаклавы и шлема дополнительно 80% био-защиты (от заражения), плюс
собственные лорные описания.

> **Важно.** Так как `_FIX` — это НОВЫЕ классы (не оригинальные), в игре
> они появятся ДОПОЛНИТЕЛЬНО к оригинальным вещам, с исходными
> характеристиками. Чтобы игроки получали именно исправленную версию,
> впишите `classname` c `_FIX` в свои типы/лут-таблицы (`types.xml` и
> т.п.) вместо оригинальных имён.
>
> Куртка, штаны и бронежилет в оригинале имеют несколько цветовых
> вариантов (`_1`, `_2`, `_1_2`, `_2_2` и т.п.) — патч сделан от первого
> варианта (`_1`). Подсумок — от варианта `Blue`. Если нужен фикс и для
> остальных цветов, добавьте по аналогии ещё один блок `_FIX`,
> наследующий соответствующий цветовой класс.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/IMPSET21_FIX` в `@IMPSET21_FIX/Addons/IMPSET21_FIX.pbo`.
3. На сервере подключите **после** оригинального мода:
   ```
   -mod=@IMPSET21;@IMPSET21_FIX
   ```
   (порядок важен — `_FIX` должен грузиться после оригинала, так как
   ссылается на его классы).

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
