# DZ_Vehicles_FIX (патч-конфиг для ванильных машин DayZ)

Отдельный аддон поверх **ванильных** машин игры (`DZ_Vehicles_Wheeled`,
идёт с сервером по умолчанию — отдельно ставить не нужно). Оригинальные
файлы игры **не трогаем** — только наследуемся и переопределяем физику.

## Какие машины покрыты

Каждая — новый класс `ИмяМашины_FIX : ИмяМашины` (как и в фиксах оружия/
одежды — чтобы применить, поменяйте classname в лут-спавнере/типах на
`_FIX`-вариант):

- **CivilianSedan** + цветовые варианты `_Wine`, `_Black`
- **OffroadHatchback** ("Нива") + `_Blue`, `_White`
- **Hatchback_02** + `_Black`, `_Blue`
- **Sedan_02** + `_Grey`, `_Red`
- **Offroad_02**
- **Truck_01_Covered** + `_Blue`, `_Orange`
- **Truck_01_Cargo** + `_Blue`, `_Grey`, `_Orange`

Итого 20 классов — у каждой машины закрыты ВСЕ её цветовые варианты, а
не только первый.

## Какие параметры выведены (всё внутри `class SimulationModule`)

- **Разгон/мощность двигателя** — `class Engine` (`torqueCurve[]` —
  крутящий момент по оборотам, обороты холостого хода/красной черты).
- **Передачи** — `class Gearbox` (`ratios[]` — передаточные числа
  вперёд, `reverse` — задняя передача, тип КПП).
- **Сцепление** — `class Clutch`.
- **Тормоза** — `class Brake`.
- **Педаль газа/чувствительность** — `class Throttle`.
- **Руль** — `class Steering`.
- **Аэродинамика** (сопротивление воздуха) — `class Aerodynamics`.
- **"Зацеп" с дорогой** — прямого параметра трения шин в ванильном
  конфиге нет (в DayZ он не выведен отдельным числом). Зацеп
  регулируется косвенно через `class Axles > Front/Rear/Middle >
  Differential` (передаточное число дифференциала, а у полноприводных
  ещё и `CentralDifferential`) и `Suspension` (жёсткость/демпфер
  подвески) — всё это в патче тоже настраивается.
- **Топливный бак/расход** — `fuelCapacity`/`fuelConsumption`.

Не тронуты: модель/текстуры, места посадки, инвентарь/багажник,
прочность кузова и дверей (`DamageSystem`), капот/двери/колёса как
отдельные лутающиеся предметы.

## Единственный файл

**`Source/DZ_Vehicles_FIX/config.cpp`**.

## Сборка PBO

1. Установите **DayZ Tools** (нужен `AddonBuilder`).
2. Соберите `Source/DZ_Vehicles_FIX` в
   `@DZ_Vehicles_FIX/Addons/DZ_Vehicles_FIX.pbo`.
3. На сервере подключите (порядок после других модов не важен, это
   патч поверх самой игры):
   ```
   -mod=@DZ_Vehicles_FIX
   ```
4. В `types.xml`/лут-спавнере замените classname нужных машин на
   `_FIX`-вариант (например `CivilianSedan` → `CivilianSedan_FIX`),
   чтобы сервер спавнил именно пропатченную версию.

Пожалуйста, соберите и протестируйте перед использованием на живом
сервере.
